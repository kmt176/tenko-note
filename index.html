点呼ノートの使い方

版 2026-10-09 17:16

有志が作った非公式のツールです。会社のものではありません。無料で使えます。アプリストアからのインストールは不要です。右上の「版」は、このアプリの版の日時です（新しい版をアップロードしたあと、アプリを閉じて開き直すと変わります）。

点呼の時刻から、拘束時間のルールを自動でチェックします。営業に役立つ天気・電車の運行情報・空港の到着便も見られます。朝のロングを受けてよいかも、渋滞予測込みで判定します。

はじめに（最初の1回）

  1. ホーム画面に追加します。
    iPhone：共有ボタン →「ホーム画面に追加」／Android：︙ →「ホーム画面に追加」
  2. メニューの一番下の設定で、乗っている車種（JPNタクシー／アルファード）を選びます。車種によって、選べる内容・決済や計算の初期値が変わります
  3. ホーム画面のアイコンから開きます。以降もいつもアイコンから開いてください。
    iPhoneは、ブラウザとアイコンで保存場所が別になります
  4. 点呼時間の「＋ 勤務を追加」で、その月度の出社日と、計画の業務前点呼・業務後点呼を入れておきます。1か月分まとめて入れておくと便利です
  5. 勤務の日は、業務前点呼の実績を入れてから売上を入力します。実績を入れるまで、その日の売上は入力できません
  6. これで準備はおしまいです。合言葉は不要です。点呼時間・売上・天気・電車・到着便が使えます。

点呼時間

  1. 「＋ 勤務を追加」で、出社日と計画の業務前点呼・業務後点呼を入れます。
  2. 勤務が終わったら、勤務カードを押して実績を入れます。計画どおりなら「計画と同じ時刻を入れる」が便利です。

ロング判定

「メニュー」→「ロング判定」で開きます。

  1. 「現在地を取得」を押します。住所が自動で入ります（違っていたら直せます）。
  2. お迎え先に向かう前なら「出発点（お迎え先）を入力する」にチェックを入れ、お迎え先を入れます。チェックすると現在地も自動で取得します。お迎え先に着いてから調べるときは、チェック不要です
  3. 目的地を入れます（例：成田空港 第1ターミナル）。
  4. 給油するなら「帰りに給油所に寄る」にチェックを入れます。陸王交通・豊玉の2か所のうち、帰り道で早く会社に着く方を自動で選びます
  5. 「時間を調べる」を押します。

行きと、帰りの2通り（高速・一般道）の時間を渋滞予測込みで出し、間に合うかを判定します。待ち時間の初期値は、お迎え先5分・目的地3分・給油5分、余裕30分です。

売上

売上は、点呼時間に入れた勤務（出社日）ごとに記録します。その日の業務前点呼（実績）を入れると、その勤務の売上を入力できるようになります（予定だけの日はまだ入力できません）。勤務中でないときは、直前の勤務が開きます。

  1. お客様が乗ったら「乗車」、降りたら「降車」を押します。押した時刻・場所（〇〇町〇丁目まで）・天気（気温・降水量）を自動で記録します。初回だけ位置情報の許可が要ります。その場で押せず、あとで(社内処理のあとなど)まとめて押すときは、右の「押し忘れ」にチェックを付けて押してください。時刻・場所は記録せず、あとで「日報から取り込む」を使ったときに日報の内容に差し替わります
  2. 降車を押すと入力画面が開くので、金額と決済を入れて保存します。内容（連続配車／配車／手上げ／乗り場）・決済は前の乗車と同じものが最初から入っています。連続配車＝手上げを取らず迎車だけを受けるモード、配車＝通常の営業中に迎車の依頼が来たとき。JPNタクシーでサンキューチケットの配車だったときは「サンキューチケット」にチェックを入れると、営業分析で分けて見られます。天気はふだん自動で、直したいときだけ「天気を直す」を開きます
  3. 出庫・休憩・回送・入庫も、ボタンで記録できます（休憩・回送はもう一度押すと終了）。
  4. 連続配車モードに入るときは「連続配車 開始」、やめるときは「連続配車 終了」を押します。開始は押した時刻の1分後で記録します（会社のシステムとのずれ対策で、1回ごとに1分少なく数えます）。モード中に乗車を押すと内容が「連続配車」になります。売上の上の「連続配車」の画面で、今週（月曜0:00〜日曜24:00）の実績と、計画を含む見込みが目標（出庫〜入庫の60%、または8〜10時の80%など。週ごとに「変える」で設定）に届くか、乗務ごとの必須（8〜10時・16〜20時で合わせて2時間）を確かめられます。計画は15分のマスを押して作ります（基本の型と、乗務ごとの計画）。過去分は「日報から取り込む」に「出庫日:」と「連続配車: 13:12-17:37, 17:54-20:30」の形で貼り付けると入ります
  5. 勤務が終わったら「納金明細書」（紙と同じ並び）に売上額①（日報の総営収）とETCなどを入れると、納金額（①−④＋⑤−⑥＋⑦アプリ手配料金−⑧B空転）が出ます。日計表の現収・未収も入れて、メーター照合がOKなら「照合済みにする」で鍵をかけます。アプリ手配料金とETC合計は、空欄なら乗車の記録から計算します。乗車の金額は現収＋未収（ETC・アプリ手配料を含む）。GO Payでも社内決済だったときは、乗車の「社内決済」にチェックを入れます
後から直す
一覧の記録を押すと、時刻・金額・決済などを直せます。押し忘れは「＋ 乗車を手で追加」で足せます。照合済みの勤務は、直す前に確認が出ます。
日報から取り込む
日報の写真を自分のAI（Claude・Geminiなど）に読ませ、書き出された文を貼り付けて、1勤務分をまとめて入れます。「AIへの頼み方をコピー」を押して、写真と一緒にAIに送ってください。取り込む前にメーター照合の結果を確かめられます。乗車ボタンで記録した日は、「突き合わせる」（金額などは日報に合わせ、位置と天気は残し、押し忘れは日報から足す）か「置き換える」かを選べます。住所から位置と天気（9日以内）も自動で入ります。取り込みでどこが変わったかは、その勤務の画面の「変更履歴」で確かめられます。
簡易入力
売上・回数・営業時間だけを入れる方法です。
過去の勤務
一番上の日付を押すと、勤務の一覧（売上つき）から選んで開けます（◀ ▶ でも移れます）。時刻ごとに「翌日」のチェックで、出庫日の次の日かどうかを決めます（出庫より前の時刻は自動でチェックが付きます）。違う日に入れてしまったときは、一番下の「勤務の修正」→「この勤務の日付を変える」でまとめて移せます。勤務の売上をまるごと消すときは、同じ所の「この勤務の売上を消す」を2回押します。
走行距離
「走行距離（高速道路の距離控除）」に出庫メーターと帰庫メーターを入れると、走行距離を出して上限（基本362km＋距離控除）と比べます。上限以上なら赤で「距離オーバー・報告が必要」と出ます。距離控除は高速道路・利用IC・片道／往復を選び、1回目を入れると2回目、3回目の欄が出ます。メーターは手で入れます（日報からは取り込みません）。基本上限は「月度の集計」の「計算の設定」で変えられます。
走行ルート（Googleマップのタイムライン）
実際に走った道と乗車の地点（番号。1万円以上は赤）を、勤務ごとに地図で見られます。
  1. はじめに（1回だけ）：Googleマップ → 右上のプロフィール →「タイムライン」をオンにします。iPhoneの 設定 → プライバシーとセキュリティ → 位置情報サービス → Google Maps を「常に」にし、「正確な位置情報」をオンにします。「Appのバックグラウンド更新」でGoogle Mapsをオン、低電力モードはオフにすると記録が途切れにくくなります。Googleマップは、アプリの一覧から上にはじいて終了しないでください。記録の間隔は自動で決まり、走っている間はおよそ1分おきです（自分では変えられません）
  2. 書き出す：Googleマップ → 右上のプロフィール → 設定 →「位置情報とプライバシー」→「タイムライン データをエクスポート」→「ファイルに保存」。何日分かまとめて書き出せます。勤務のたびでなくてもかまいません
  3. 読み込む：売上の「走行ルート」→「タイムラインを読み込む」で、保存したファイル（Timeline.json）を選びます。ファイルに入っている勤務の分が、まとめて入ります
  4. 見る：「全画面で見る」で画面いっぱいに広がります（「閉じる」で戻る）。1つの乗車だけ見るときは、欄の選択で「No.○」を選ぶか、乗車の一覧の「ルート ›」を押します。乗車〜降車の道とその区間の距離が出ます。
ルートはこのスマホの中だけに保存し、どこにも送りません。書き出したファイルには全期間の移動の記録が入っているので、読み込んだあとは人に渡さず、要らなければ消してください。距離は約1分ごとの位置から出すので、メーターより少し短く出ます。
月度の集計
上の「月度の集計」で、月度（締め日ごと）の税抜営収・概算給与・賞与積立（6月度と12月度は半年分の賞与見込みも）・時間帯別の売上・決済別・納金の合計と、勤務ごとの一覧を見られます。率は一番下の「計算の設定」で変えられます。いちばん上に目標（税抜営収）を入れると、残りの勤務（点呼時間の今日以降の予定）で1勤務いくら必要かと、今のペースの見込みを出します。
営業分析
上の「営業分析」で、曜日別・時間帯×曜日・乗車の多い場所・降ろしたあと次が早い場所・営業のしかた別（連続配車／配車／手上げ／乗り場）・天気別の傾向を見られます。期間は「この月度」「直近3か月」「全部」から選べます。金額はETC・アプリ手配料を除いたメーター料金の税抜です。
過去の分をまとめて取り込む
「日報から取り込む」には、何日分でも続けて貼り付けられます（「出庫日:」ごとに1日）。「業務前点呼: 12:56」「業務後点呼: 08:48」の行があれば、点呼時間にその日の勤務がなくても作って取り込みます。すでに記録がある日は取り込みません。

営業（分）・待ち（分）・アプリ料（配車でGOPAY以外は200円）は自動で計算します。住所は国土地理院、天気は気象庁アメダス（近くの観測所）のデータです。データはこのスマホの中だけに保存されます。

仲間の速報（グループ）

同じグループの仲間どうしで、1万円以上の乗車を見られます（仲間の合言葉が必要です）。グループを作りたいときは、代表になる方が紹介者（管理者）に連絡してください。合言葉を作成します。

天気・電車・到着便

「メニュー」の上のボタンで切り替えます。合言葉なしで使えます。開くたびに新しい情報を読み込みます（「更新」でも読み込めます）。

天気
気象庁の東京地方の予報です。降水確率50%以上の時間帯に色が付きます。雨雲の動きは下のボタンから見られます。
電車
東京メトロ・都営の運行情報です。乱れのある路線を上に出します。JR・東武・西武は公式サイトを開きます。
到着便
羽田・成田に着くJAL・ANAの便です。これから60分に着く便の数、15分以上の遅れ、23時以降（電車が少ない時間）の便が分かります。

注意

  • 操作は必ず停車中に行ってください。
  • データはこのスマホの中だけに保存されます。他の人からは見えません。
  • 機種変更に備えて、月1回「バックアップ・機種変更」でデータをコピーしてください。バックアップの文字は暗号化されます。パスワードを付けた場合、忘れると復元できません。
  • スマホには画面ロック（パスコード・指紋・顔認証）を設定してください。
  • ロング判定の行きの時間は、今の渋滞（事故渋滞を含む）を反映しています。帰りの時間は「いつもの混み方」からの予測で、これから起きる事故や、工事の車線規制は含まれません。工事・事故の情報は、ロング判定の画面のボタンから首都高・NEXCOの公式サイトで確認してください。

日報から取り込む

  1. 「AIへの頼み方をコピー」を押します。
  2. 自分のAI（Claude・Gemini・ChatGPTなど）に、日報の写真とコピーした文を送ります。氏名の部分は隠して撮ってもかまいません
  3. AIが書き出した文を全部コピーして、下に貼り付け、「確かめる」を押します。

乗車の入力

ETC・アプリ手配料（社内決済の200円）を含めた金額を入れます
天気を直す（ふだんは自動）
乗車の場所と時刻の天気を気象庁のアメダスから自動で記録します。場所が取れなかったとき・9日より前の取り込み・自動の判定を直したいときだけ選んでください。

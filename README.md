# 点呼ノート 使い方

タクシー乗務員向けのスマホ用ページです。点呼時刻から拘束時間のルールをチェックし、売上の記録や、営業に役立つ天気・電車・空港の到着便の確認ができます。

- ページ：https://kmt176.github.io/tenko-note/
- **有志が作った非公式のツールです。会社のものではありません。**
- 無料で使えます。アプリストアからのインストールは不要です。

---

## 始め方

1. スマホで https://kmt176.github.io/tenko-note/ を開きます。
2. **ホーム画面に追加**します。
   - iPhone：共有ボタン（□に↑）→「ホーム画面に追加」
   - Android（Chrome）：右上の︙ →「ホーム画面に追加」
3. **ホーム画面のアイコンから開きます。** 以降も必ずアイコンから開いてください（iPhoneは、ブラウザとアイコンで保存場所が別になります）。

4. **点呼時間の「＋ 勤務を追加」で、その月度の出社日と、計画の業務前点呼・業務後点呼を入れておきます。**（1か月分まとめて入れておくと便利です）
5. 勤務の日は、**業務前点呼の実績を入れてから**売上を入力します。実績を入れるまで、その日の売上は入力できません（売上の画面の「業務前点呼（実績）を入れる」ボタンからも入れられます）。

合言葉は要りません。

---

## 画面

下のボタンで切り替えます：**使い方｜点呼時間｜売上｜メニュー**

### 点呼時間
- 「＋ 勤務を追加」で、出社日と**計画**の業務前点呼・業務後点呼を入れます。勤務が終わったら、勤務カードを押して**実績**を入れます。
- 自動で表示するもの
  - 業務後点呼の期限（2日平均21時間を守れる時刻）
  - **21時間（報告書）○○まで**（黄）：会社のルールでは、1回の拘束が21時間を超えると報告書が必要です（ちょうど21時間までは不要）。業務前点呼の実績を入れると、その時刻から21時間後を出します（実績がまだのときは計画から）。超えた勤務には「21時間超え・報告書」の印が付きます
  - **22時間（法令の上限）○○まで**（赤）：ちょうど22時間まではよく、過ぎると違反です
  - 前の勤務からの休息時間
  - 月度ごとの拘束時間の合計と、上限までの残り
- 色の意味：緑＝ルール内、黄＝注意、赤＝違反

### 売上
売上は、**点呼時間に入れた勤務（出社日）ごと**に記録します。その日の**業務前点呼（実績）**を点呼時間に入れると、その勤務の売上を入力できるようになります（予定だけの日はまだ入力できません。売上の画面の「業務前点呼（実績）を入れる」ボタンからも入れられます）。勤務中でないときに売上を開くと、直前の勤務が出ます（明けの日の取り込み・照合用）。

1. お客様が乗ったら「**乗車**」、降りたら「**降車**」を押します。押した時刻・場所（〇〇町〇丁目まで）・天気（気温・降水量）を自動で記録します。
2. 降車を押すと入力画面が開くので、**金額**と**決済**を入れて保存します。
3. 出庫・休憩・回送・入庫もボタンで記録できます（休憩・回送はもう一度押すと終了）。連続配車モードに入るときは「連続配車 開始」、やめるときは「連続配車 終了」を押します。モード中の乗車は内容が「連続配車」になります。売上の上の「連続配車」の画面で、今週（月曜0:00〜日曜24:00）の実績と計画を含む見込み、乗務ごとの必須（8〜10時・16〜20時で合わせて2時間）を確かめ、15分のマスで計画を作れます。
4. 勤務が終わったら「**納金明細書**」（紙の納金明細書と同じ並び）に、**売上額①**（日報の総営収）、アプリ手配料金⑦、ETC合計⑤、ETC会社負担⑥を入れます。②日計表合計・③その他未収・④未収計・B空転⑧・**納金額**（①−④＋⑤−⑥＋⑦−⑧）は自動で出ます。伝達事項も書けます。
   - アプリ手配料金とETC合計は、空欄なら乗車の記録から計算します。
   - 乗車の「金額」は**現収＋未収**です。ETCとアプリ手配料（社内決済の200円）も含めて入れます。
   - **社内決済**のチェック：配車でGO Pay以外は自動でチェックが入り、アプリ手配料200円として数えます。GO Payでも社内決済だったときは、チェックを入れてください。入力画面に「メーター料金（金額−ETC−アプリ手配料）」が出るので、日報の合計金額と見比べられます。
   - 下の「日計表と照合」に日計表の現収・未収を入れると、照合の結果が出ます。メーター照合がOKなら「照合済みにする」で鍵をかけます。
5. 「**走行距離（高速道路の距離控除）**」に**出庫メーター**と**帰庫メーター**を入れると、走行距離（帰庫−出庫）を出して、上限（基本362km＋距離控除）と比べます。**上限以上なら赤で「距離オーバー・報告が必要」**と出ます。
   - 距離控除は、高速道路・利用IC・片道／往復を選びます。1回目を入れると2回目、2回目を入れると3回目の欄が出ます（消すときは高速道路を「（なし）」に）。
   - 控除距離は「高速道路(距離控除用)距離一覧表」（2021年5月27日現在）のとおりです。出庫・帰庫メーターは手で入れます（日報の走行距離はずれることがあるため、取り込みません）。
6. 「**走行ルート**」：Googleマップの「タイムライン」を使っている人は、書き出したファイルを読み込むと、勤務ごとに実際に走った道と乗車の地点（番号。1万円以上は赤）を地図で見られます。
   - **はじめに（1回だけ）**：Googleマップ → 右上のプロフィール →「タイムライン」をオン。iPhoneの 設定 → プライバシーとセキュリティ → 位置情報サービス → Google Maps を「常に」、「正確な位置情報」をオン。「Appのバックグラウンド更新」でGoogle Mapsをオン、低電力モードはオフにすると記録が途切れにくくなります。記録の間隔は自動で決まり、走っている間はおよそ1分おきです（自分では変えられません）。
   - **書き出す**：Googleマップ → 右上のプロフィール → 設定 →「位置情報とプライバシー」→「タイムライン データをエクスポート」→「ファイルに保存」。何日分かまとめてでもかまいません。
   - **読み込む**：点呼ノートの「タイムラインを読み込む」でそのファイルを選びます。ファイルに入っている勤務の分がまとめて入ります。
   - **見る**：「全画面で見る」で地図が画面いっぱいに広がります（「閉じる」で戻る）。
   - **1つの乗車だけ**見るときは、走行ルートの欄の選択で「No.○」を選ぶか、乗車の一覧の「**ルート ›**」を押します。乗車〜降車の間の道と、その区間の距離が出ます。
   - ルートはスマホの中だけに保存し、どこにも送りません。書き出したファイルには全期間の移動の記録が入っているので、人に渡さず、要らなければ消してください。距離は約1分ごとの位置から出すので、メーターより少し短く出ます。地図は国土地理院の地理院タイルです。
7. 上の「**月度の集計**」で、月度（締め日ごと）の売上・税抜・給与見込み・決済別・納金の合計と、勤務ごとの一覧を見られます。税抜の掛け率と歩合率は「計算の設定」で変えられます。

- 一覧の記録を押すと、後から直せます。押し忘れは「＋ 乗車を手で追加」で足せます。照合済みの勤務は、直す前に確認が出ます。
- **押し忘れ**：その場で乗車・降車ボタンを押せず、あとで（社内処理のあとなど）まとめて押すときは、ボタンの右の「押し忘れ」にチェックを付けて押します。この乗車の時刻・位置はこのスマホの記録を使わず、あとで「日報から取り込む」をしたときに日報の内容に差し替わります。すでに記録した乗車を「押し忘れ」にしたいときは、一覧から開いて「記録を直す」画面でチェックします（説明文入り）。
- **過去の勤務**は、一番上の日付を押して一覧から選ぶか、◀ ▶ で開いて入力できます。日付をまたいだ時刻は「翌日」にチェックします（出庫より前の時刻は自動でチェックが付きます）。違う日に入れてしまったときは、画面の一番下の「勤務の修正」→「この勤務の日付を変える」でまとめて移せます。勤務の売上をまるごと消すときは、同じ所の「この勤務の売上を消す」（2回押し）です。
- **日報から取り込む**：日報の写真を自分のAI（Claude・Gemini・ChatGPTなど、無料版で可）に読ませて、1勤務分をまとめて入れられます。
  1. 売上の「日報から取り込む（貼り付け）」→「AIへの頼み方をコピー」を押します。
  2. 自分のAIに、日報の写真とコピーした文を送ります（氏名は隠して撮ってもかまいません）。
  3. AIが書き出した文を貼り付けて「確かめる」→ メーター照合を見て「取り込む」。
  - すでに乗車ボタンで記録した日に取り込むときは、**突き合わせる**（時刻の近い乗車を組み合わせて金額などを日報に合わせ、ボタンで記録した位置・天気は残す。押し忘れた乗車は日報から足す。日報にない記録は「日報になし」と印を付けて残す）か、**置き換える**（日報の内容にまるごと置き換える）かを選べます。「押し忘れ」にチェックを付けた乗車は、時刻がずれていても、残った日報の行に順番で正しく組み合わせます。
  - AIは読み間違えることがあります。メーター照合がNGのときは、日報と見比べて直してください。
  - 取り込みで何が変わったかは、その勤務の画面の「変更履歴」で確かめられます（直近20回分）。
  - 住所から位置と天気も入ります（天気は気象庁に残っている9日以内の分だけ）。日報の写真や住所は、自分で選んだAIに送ることになるので、会社の決まりも確かめてください。
- 「簡易入力」に切り替えると、売上・回数・営業時間だけを入れられます。
- 内容は「**連続配車**」（手上げを取らず、迎車だけを受け続けるモード）・「**配車**」（通常の営業中に迎車の依頼が来たとき）・「手上げ」・「**乗り場**」などから選びます。計算は連続配車も配車と同じです。社内決済（アプリ手配料200円）のチェックは、連続配車と配車のときだけ出ます。日報には連続配車・乗り場の区別がないので、「突き合わせる」で取り込んでも、ボタンで連続配車・乗り場にした乗車はそのまま残ります。
- 営業（分）・待ち（分）・アプリ料（配車・連続配車でGOPAY以外は200円）は自動で計算します。
- 乗車ごとに**営業分単価**（メーター料金÷営業分）と**実単価**（メーター料金÷（待ち＋営業分））を出します。メーター料金は、金額からETCとアプリ手配料を引いた額（日報の合計金額）です。
- 「月度の集計」は**税抜営収**（総営収×0.9）が中心です。**概算給与**（税抜×0.62×90%）と**賞与積立**（税抜×0.62×10%）を出し、6月度は12月度〜5月度、12月度は6月度〜11月度の積立の合計を「賞与見込み」として出します。率と賞与の割合は「計算の設定」で変えられます。
- **目標**：月度の集計のいちばん上に目標（税抜営収）を入れると、残りの勤務（点呼時間の今日以降の予定）で1勤務あたりいくら必要かと、今のペースの見込みを出します。
- **営業分析**：「営業分析」で、曜日別・時間帯×曜日・乗車の多い場所・降ろしたあと次が早い場所・営業のしかた別・天気別の傾向を見られます（期間は この月度／直近3か月／全部）。
- **過去の分をまとめて取り込む**：「日報から取り込む」に何日分でも続けて貼り付けられます（「出庫日:」ごとに1日）。「業務前点呼:」「業務後点呼:」の行があれば、点呼時間にその日がなくても作って取り込みます。すでに記録がある日は取り込みません。
- **時間帯別の売上**：乗車した時刻の時間帯ごとに、月度は1勤務あたりの平均と合計、各勤務は合計を棒グラフで出します（ETC・アプリ手配料を除いたメーター料金）。
- **実車率（時間）**＝実車時間÷営業時間（実車＋空車。休憩・回送を除く）、**時間あたり（税抜）**＝税抜営収÷営業時間。日報の実車率は距離（営走km÷全走km）なので、数字は違います。付け待ちの多い日は、距離の実車率だけ高く見えます。
- 上の合計には、回数・平均単価・実車時間に加えて、**空車時間**（出庫〜入庫から実車・休憩・回送を引いた時間）と**税抜営収**（総営収×0.9。総営収はETC・アプリ料を含まない）を出します。

### メニュー（天気・電車・到着便）
- **天気**：気象庁の東京地方の予報。降水確率50%以上に色が付きます。
- **電車**：東京メトロ・都営の運行情報。JR・東武・西武は公式サイトを開きます。
- **到着便**：羽田・成田に着くJAL・ANAの便。これから60分の到着数、15分以上の遅れ、23時以降の便が分かります。

### 仲間の速報（グループ）
- 同じグループの仲間どうしで、金額の高い乗車（既定1万円以上。管理者が変更できます）を見られる機能があります（合言葉が必要です）。
- **グループを作りたいときは、代表になる方が紹介者（管理者）に連絡してください。合言葉を作成します。**

## データとバックアップ

- **データは自分のスマホの中だけに保存されます。** 他の人からは見えません。
- 住所（〇〇町〇丁目）を調べるときだけ、乗車・降車の位置（緯度・経度）を国土地理院に送ります。天気は近くの観測所のデータを読むだけで、位置は送りません。
- 機種変更やアプリの削除をするとデータが消えます。月1回ほど、点呼時間の画面の「バックアップ・機種変更」で「バックアップを作る」→「コピー」を押し、メモなどに保存してください。新しいスマホでは貼り付けて「復元」を押します（点呼と売上の両方が戻ります）。
- バックアップの文字は暗号化されていて、見ても内容は分かりません。さらに**パスワード**を付けると、パスワードを知らない人は誰も復元できなくなります（**忘れると自分でも復元できません**）。
- スマホには画面ロック（パスコード・指紋・顔認証）を設定してください。スマホの中のデータは、画面ロックで守られます。

## 注意

- **操作は必ず停車中に行ってください。**
- 天気・電車・到着便・住所は、公開されている情報をそのまま表示しています。正確さは保証されません。

## 使っているデータ

- 天気予報・アメダス：気象庁
- 住所（〇〇町〇丁目）：国土地理院 逆ジオコーダ
- 運行情報・到着便：公共交通オープンデータセンター（東京メトロ・東京都交通局・日本航空・全日空）

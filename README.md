# 点呼ノート 使い方

タクシー乗務員向けのスマホ用ページです。点呼時刻から拘束時間のルールをチェックし、売上の記録や、営業に役立つ天気・電車・空港の到着便の確認ができます。

- ページ：https://kmt176.github.io/tenko-note/
- **有志が作った非公式のツールです。会社のものではありません。**
- 無料で使えます。アプリストアからのインストールは不要です。

---

## 始め方

1. スマホで https://kmt176.github.io/tenko-note/ を開きます。
2. **ホーム画面に追加**します。
   - iPhone：共有ボタン（□に↑）→「ホーム画面に追加」
   - Android（Chrome）：右上の︙ →「ホーム画面に追加」
3. **ホーム画面のアイコンから開きます。** 以降も必ずアイコンから開いてください（iPhoneは、ブラウザとアイコンで保存場所が別になります）。

合言葉は要りません。

---

## 画面

下のボタンで切り替えます：**使い方｜点呼時間｜売上｜メニュー**

### 点呼時間
- 「＋ 勤務を追加」で、出社日と**計画**の業務前点呼・業務後点呼を入れます。勤務が終わったら、勤務カードを押して**実績**を入れます。
- 自動で表示するもの
  - 業務後点呼の期限（2日平均21時間を守れる時刻）
  - 22時間を超える時刻（赤）
  - 前の勤務からの休息時間
  - 月度ごとの拘束時間の合計と、上限までの残り
- 色の意味：緑＝ルール内、黄＝注意、赤＝違反

### 売上
1. お客様が乗ったら「**乗車**」、降りたら「**降車**」を押します。押した時刻・場所（〇〇町〇丁目まで）・天気（気温・降水量）を自動で記録します。
2. 降車を押すと入力画面が開くので、**金額**と**決済**を入れて保存します。
3. 出庫・休憩・回送・入庫もボタンで記録できます（休憩・回送はもう一度押すと終了）。
4. 勤務が終わったら「**納金明細書**」（紙の納金明細書と同じ並び）に、**売上額①**（日報の総営収）、アプリ手配料金、ETC合計⑤、ETC会社負担⑥を入れます。②日計表合計・③その他未収・④未収計・B空転・**現金（納金）**は自動で出ます。伝達事項も書けます。
   - アプリ手配料金とETC合計は、空欄なら乗車の記録から計算します。
   - 下の「日計表と照合」に日計表の現収・未収を入れると、照合の結果が出ます。メーター照合がOKなら「照合済みにする」で鍵をかけます。
5. 上の「**月度の集計**」で、月度（締め日ごと）の売上・税抜・給与見込み・決済別・納金の合計と、勤務ごとの一覧を見られます。税抜の掛け率と歩合率は「計算の設定」で変えられます。

- 一覧の記録を押すと、後から直せます。押し忘れは「＋ 乗車を手で追加」で足せます。照合済みの勤務は、直す前に確認が出ます。
- **過去の勤務**は「出庫日を選ぶ」で開いて入力できます。日付をまたいだ時刻は「翌日」にチェックします（出庫より前の時刻は自動でチェックが付きます）。違う日に入れてしまったときは「この勤務の日付を変える」でまとめて移せます。
- **日報から取り込む**：日報の写真を自分のAI（Claude・Gemini・ChatGPTなど、無料版で可）に読ませて、1勤務分をまとめて入れられます。
  1. 売上の「日報から取り込む（貼り付け）」→「AIへの頼み方をコピー」を押します。
  2. 自分のAIに、日報の写真とコピーした文を送ります（氏名は隠して撮ってもかまいません）。
  3. AIが書き出した文を貼り付けて「確かめる」→ メーター照合を見て「取り込む」。
  - AIは読み間違えることがあります。メーター照合がNGのときは、日報と見比べて直してください。
  - 住所から位置と天気も入ります（天気は気象庁に残っている9日以内の分だけ）。日報の写真や住所は、自分で選んだAIに送ることになるので、会社の決まりも確かめてください。
- 「簡易入力」に切り替えると、売上・回数・営業時間だけを入れられます。
- 営業（分）・待ち（分）・アプリ料（配車でGOPAY以外は200円）は自動で計算します。

### メニュー（天気・電車・到着便）
- **天気**：気象庁の東京地方の予報。降水確率50%以上に色が付きます。
- **電車**：東京メトロ・都営の運行情報。JR・東武・西武は公式サイトを開きます。
- **到着便**：羽田・成田に着くJAL・ANAの便。これから60分の到着数、15分以上の遅れ、23時以降の便が分かります。

## データとバックアップ

- **データは自分のスマホの中だけに保存されます。** 他の人からは見えません。
- 住所（〇〇町〇丁目）を調べるときだけ、乗車・降車の位置（緯度・経度）を国土地理院に送ります。天気は近くの観測所のデータを読むだけで、位置は送りません。
- 機種変更やアプリの削除をするとデータが消えます。月1回ほど、点呼時間の画面の「バックアップ・機種変更」で「バックアップを作る」→「コピー」を押し、メモなどに保存してください。新しいスマホでは貼り付けて「復元」を押します（点呼と売上の両方が戻ります）。
- バックアップの文字は暗号化されていて、見ても内容は分かりません。さらに**パスワード**を付けると、パスワードを知らない人は誰も復元できなくなります（**忘れると自分でも復元できません**）。
- スマホには画面ロック（パスコード・指紋・顔認証）を設定してください。スマホの中のデータは、画面ロックで守られます。

## 注意

- **操作は必ず停車中に行ってください。**
- 天気・電車・到着便・住所は、公開されている情報をそのまま表示しています。正確さは保証されません。

## 使っているデータ

- 天気予報・アメダス：気象庁
- 住所（〇〇町〇丁目）：国土地理院 逆ジオコーダ
- 運行情報・到着便：公共交通オープンデータセンター（東京メトロ・東京都交通局・日本航空・全日空）
